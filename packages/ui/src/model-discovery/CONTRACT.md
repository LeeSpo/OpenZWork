# 模型拉取选择弹窗

弹窗拥有当前 Provider 的候选、选择和保存反馈；hook 通过 ProviderSettingsService 读取，不直连供应商。查询以 Provider 和打开代际隔离，关闭或切换时拒收迟到响应。保存逐项复用父组件已有 onAddModel；成功不再选，失败保留。缺配置交还现有模型编辑器，配置 owner 与当前会话选择不变。

## OpenZWork(OZ-F015)：一键更新模型资料

公开入口 `ModelCatalogUpdateButton` 放在供应商模型列表旁。点击即调用所属 Environment 的 `updateModelsFromCatalog(providerId)`，按已有模型的名称匹配 models.dev 并写入个人覆盖配置。弹窗显示匹配数量、已写入的字段、推理档位变化、未找到的模型，以及因目录分歧跳过的字段。零写入时显示“本次未更新模型资料”。字段归属由服务判断。

读写都走 hook，组件不接触文件、凭据或网络。错误按服务返回的错误码分成四类文案：无法连接、超时、返回内容异常、保存失败，每条都说明配置未改变，并提供重试。服务或供应商切换、关闭弹窗后，通过代际丢弃迟到反馈。进行中禁止重复提交，也不能关闭弹窗。更新由点击触发，不在 effect 中自动执行，避免重放造成第二次写入。
