# model-catalog-update

按用户已经添加的模型 ID，从公开目录补全资料和推理档位。本模块只做确定性匹配与字段归属，不拉取网络、不增删模型、不改内置目录文件。

不变量：

- 按已有模型的规范化名称匹配，结果按原始模型 ID 返回。资料逐字段取过半值，返回有值但没有过半结果的字段。
- 可写字段固定为上下文窗口、最大输出、工具调用、结构化输出、输入输出模态和推理档位列表；enabled 与推理参数映射等其它字段永不来自目录。
- 用户改过的字段不覆盖；仅当记录值仍等于当前个人值时，才允许目录再次刷新该字段。
- 推理档位优先采用目录中首个至少有两种强度的列表，其次取首个明确列表。档位沿用现有配置 schema 写入。
